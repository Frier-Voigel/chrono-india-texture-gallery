# Chrono India — Texture Gallery

A static pixel-art texture asset browser and download portal for **Chrono India: The Shattered Timeline**.

🌐 **Live site:** [chrono-india-texture-gallery.pages.dev](https://chrono-india-texture-gallery.pages.dev)

---

## Features

- 🔍 **Fuzzy search** across texture names and tags (Fuse.js)
- 🗂️ **Filter by category** — Terrain, Architecture, Character, VFX, Props
- ⏳ **Filter by era** — Vedic, Mughal, Colonial, Modern, Future
- ✦ **Tileable toggle** — show only seamless tileable textures
- 🖼️ **Full-screen preview modal** — keyboard navigable (Esc / ←→)
- ⬇️ **One-click PNG download** per texture
- 📦 **Category ZIP bundles** for bulk download
- 📋 **Copy generation prompt** to clipboard
- 🎨 **Pixel-art crisp rendering** — `image-rendering: pixelated` everywhere
- ♿ **WCAG AA accessible** — focus trap, aria-pressed, aria-live, keyboard nav

## Tech Stack

| Tool | Purpose |
|---|---|
| **Astro 4** | Static site generator |
| **Tailwind CSS v3** | Utility-first styling |
| **Fuse.js** | Client-side fuzzy search |
| **Sharp** | Build-time WebP thumbnail generation |
| **JSZip** | Category ZIP bundles |
| **Cloudflare Pages** | Hosting & CDN |

## Folder Structure

```
texture-gallery/
├── public/
│   ├── textures/{category}/   ← drop PNG assets here
│   ├── thumbnails/{category}/ ← auto-generated by build:thumbs
│   ├── zip/                   ← auto-generated by build:zips
│   └── gallery.js             ← combined client-side script
├── src/
│   ├── components/            ← Astro UI components
│   ├── content/textures/      ← .md frontmatter per texture
│   ├── layouts/               ← Base HTML shell
│   ├── pages/                 ← index, [category], texture/[slug], 404, about
│   ├── styles/global.css      ← Tailwind + pixel-art overrides
│   └── utils/                 ← textureManifest.ts, palette.ts
└── scripts/
    ├── generate-thumbnails.mjs
    ├── generate-manifest.mjs
    └── generate-zips.mjs
```

## Development

```bash
npm install
npm run dev          # → http://localhost:4321
```

## Adding New Textures

1. Drop `category_name_01.png` into `public/textures/{category}/`
2. Create `src/content/textures/{category}/category_name_01.md` with frontmatter
3. Run `npm run build:thumbs` to generate WebP thumbnails
4. Run `npm run build` — done ✅

### Frontmatter Schema

```yaml
---
title: "Human-readable Title"
category: "terrain"          # terrain | architecture | character | vfx | props
tags: ["tag1", "tag2"]
resolution: "16x16"
tileable: true
palette: ["#C1894E", "#8B5E3C"]
era: "mughal"                # vedic | mughal | colonial | modern | future | universal
prompt: "Nano Banana generation prompt text..."
added: 2026-10-19
---
```

## Build Commands

```bash
npm run dev           # dev server at :4321
npm run build         # full production build (thumbs + manifest + astro)
npm run build:thumbs  # Sharp → WebP thumbnails from /public/textures/
npm run build:manifest # JSON index of all texture files
npm run build:zips    # category ZIP bundles for bulk download
npx astro preview     # preview production build locally
```

## Deployment (Cloudflare Pages)

1. Push this folder to a GitHub repo
2. Log into [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create
3. Connect GitHub → select repo
4. Build settings:
   - Framework: **Astro**
   - Build command: `npm run build`
   - Output directory: `dist`
5. Deploy — auto-deploys on every push to `main`

### GitHub Actions (alternative)

Set secrets `CF_API_TOKEN` and `CF_ACCOUNT_ID` — the workflow at `.github/workflows/deploy.yml` handles everything automatically.
